# Public Images

Place your product and brand images here.

## Required files

| File | Purpose |
|------|---------|
| `logo.png` | Nanhe brand logo (shown in Navbar & Footer) |
| `og-image.jpg` | Open Graph / social share image (1200×630 recommended) |

## Product images

Product images are currently sourced from Unsplash placeholder URLs.
To replace them, edit `src/data/products.js` and change the `image` field
for each product to a local path like `/images/rasmalai.jpg`.

Example:
```js
image: "/images/rasmalai.jpg",
```
